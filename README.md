## Features

- A simple calculator application developed to handle basic arithmetic operations. 
- There are buttons for each number and operation.
- The result area shows the current input and result.
- Some features are: button to clear the screen, button to clear the last digit and button to clear the last entry.
- The calculator includes also percent, square, squareroot and equal buttons.
